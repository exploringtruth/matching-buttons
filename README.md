# Matching Buttons

Welcome to **Matching Buttons**! Your goal is to align both hands over matching button pairs simultaneously, then hold click for 3 seconds to restore the connection.


## Controls

The game requires split-brain coordination using two separate controls:

| Action | Left Hand | Right Hand |
| :--- | :---: | :---: |
| **Move Up** | <kbd>W</kbd> | <kbd>▲ Up</kbd> |
| **Move Left** | <kbd>A</kbd> | <kbd>◄ Left</kbd> |
| **Move Down** | <kbd>S</kbd> | <kbd>▼ Down</kbd> |
| **Move Right** | <kbd>D</kbd> | <kbd>► Right</kbd> |
| **Hold Click** | <kbd>Spacebar</kbd> | <kbd>Enter</kbd> |

-  **Reset Game**: Press <kbd>R</kbd> on the win screen to restart.

## How to Play

1. **Locate Matching Pairs**

   Identify matching color buttons on the left and right sides of the screen.


2. **Position the Hands**

   - Move the **Left Hand** over one of the matching color buttons using <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>.
   - Move the **Right Hand** over the corresponding matching button using the **Arrow Keys**.
   - Note: Cross-hand matching is also valid as long as both matching buttons are covered simultaneously.


3. **Hold to Lock**

   - Press and hold <kbd>Spacebar</kbd> (Left Hand) and <kbd>Enter</kbd> (Right Hand) at the same time while aligned over the matching buttons.
   - Hold for the required time (3.0s) until the button pair locks into place.


4. **Win Condition**

   - Successfully lock all button pairs to clear the stage!
